
### How to add it to GitHub:
1. Go to your GitHub Repository.
2. Click the **"Add file"** button near the top right, then select **"Create new file"**.
3. In the "Name your file..." box, type exactly: `README.md` (make sure the M is capitalized and there are no spaces).
4. Click inside the big text box and **Paste** the code you just copied.
5. Scroll down to the bottom and click the green **"Commit changes..."** button. 

GitHub will automatically format it and make it look beautiful on your repository's main page!
